    À propos de l'observatoire

    Ce site est un observatoire indépendant, non partisan et non commercial. Voici qui l'écrit, comment, et ce qu'il faut savoir pour le lire avec un regard critique.

    L'auteur : une intelligence artificielle#

    Les textes de ce site ont été rédigés par Claude, un modèle d'intelligence artificielle développé par l'entreprise Anthropic. Ce choix est assumé et affiché sur chaque page, dans la signature et dans les métadonnées. Il répond à une demande de l'éditeur, qui souhaite rester anonyme.

    Concrètement, le travail s'est déroulé ainsi :

    1. Corpus de départ : deux rapports de recherche fournis par l'éditeur, consacrés aux panoramas mondiaux de l'extrême droite et de l'extrême gauche, avec plus de deux cents références.
    2. Recherche complémentaire : une vérification et une mise à jour documentaire à la date du 27 septembre 2026, portant sur les scrutins de 2025-2026 (Allemagne, Hongrie, Pays-Bas, Portugal, Tchéquie, Pologne, Roumanie, Chili, Colombie, Bolivie, Argentine, Royaume-Uni, France), les décisions de justice (AfD, Le Pen), les rapports Europol et V-Dem 2026 et les désignations terroristes américaines.
    3. Rédaction et corrections : les textes ont été entièrement réécrits, et certaines affirmations des rapports initiaux ont été corrigées lorsque les faits ultérieurs les contredisaient (par exemple l'annonce d'un effondrement de Die Linke, démentie par ses résultats de 2025-2026).
    4. Sélection des sources : les références jugées peu fiables (forums, réseaux sociaux, copies non autorisées d'ouvrages) ont été écartées. Les sources partisanes sont conservées et signalées comme sources primaires.

    Limites et vigilance#

    Une IA peut se tromper : mal lire une source, confondre deux dates, reproduire un biais de la littérature. Pour limiter ces risques, chaque affirmation factuelle importante renvoie à une source identifiable, et les données chiffrées sont regroupées dans des tableaux téléchargeables. Nous vous invitons à vérifier, en particulier :

    • les résultats électoraux provisoires (Berlin et Mecklembourg, septembre 2026) ;
    • les chiffres issus de sondages, qui ne sont pas des résultats ;
    • les classements idéologiques, qui relèvent de l'interprétation et font débat.

    Quelques éléments n'ont pas pu être vérifiés et sont signalés comme tels par un tiret dans les tableaux. Les deux diaporamas du corpus initial, composés uniquement d'images, n'ont pas pu être exploités.

    Neutralité et symétrie#

    La ligne éditoriale est celle d'un observatoire analytique : appliquer aux deux extrêmes les mêmes critères (voir Méthode), distinguer faits, analyses et revendications, et présenter les débats plutôt que les trancher lorsque la recherche est elle-même divisée. Neutralité ne signifie pas relativisme : les faits établis — une condamnation, un attentat, un résultat — sont énoncés comme tels, et les théories complotistes sont qualifiées comme telles.

    Signaler une erreur#

    Le code source du site est public sur GitHub. Pour signaler une erreur factuelle, une source morte ou un classement contestable, vous pouvez ouvrir une issue sur le dépôt github.com/ouaisfieu/extreme. Les corrections sont datées dans le flux des mises à jour.

    Architecture : un site sans build#

    Le site est construit selon une approche JAMstack minimaliste, sans étape de compilation :

    • Markup : chaque page est un fichier HTML statique complet, lisible sans JavaScript, directement éditable et servi tel quel par GitHub Pages ;
    • JavaScript : un seul script d'amélioration progressive (recherche, filtres, tri des tableaux, thème sombre, lecteur vidéo différé) ;
    • API : des fichiers JSON et CSV statiques dans /data — index de recherche, élections, chronologie, glossaire, acteurs, sources — réutilisables par d'autres sites ou outils (voir Données ouvertes).

    Le site n'utilise ni cookie, ni traceur, ni police ou bibliothèque externe. Les vidéos YouTube ne sont chargées, en mode sans cookie, qu'après un clic.

    Référencement et web sémantique#

    Chaque page embarque des données structurées schema.org en JSON-LD : Article ou ScholarlyArticle avec auteur, dates, citations et entités (about, mentions, liées à leurs notices encyclopédiques par sameAs) ; BreadcrumbList ; FAQPage ; DefinedTermSet pour le glossaire ; Dataset pour les tableaux électoraux ; VideoObject pour les vidéos ; ItemList d'Event, d'Organization et de Person. Les métadonnées Open Graph et Dublin Core, un plan de site XML, un flux Atom, un fichier llms.txt et une description OpenSearch complètent l'ensemble.
