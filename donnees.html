    Données

    Données ouvertes

    Le site expose ses données sous forme de fichiers statiques : une « API » sans serveur, sans clé et sans inscription, réutilisable dans un tableur, un script ou un autre site.

    Fichiers disponibles#

    Points d'accès
    FichierFormatContenu
    data/elections.jsonJSONQuinze tableaux électoraux : colonnes, lignes, notes et identifiants des sources. Chaque tableau existe aussi en CSV (data/<id>.csv, par exemple de-be-2026.csv).
    data/chronologie.json · .csvJSON, CSVÉvénements : date ISO, titre, texte, camp, lieu, URL des sources.
    data/acteurs.json · .csvJSON, CSVOrganisations : nom, sigle, pays, camp, type, famille, groupe au Parlement européen, situation 2026, lien sameAs.
    data/glossaire.jsonJSONTermes, identifiants d'ancre, camp, définition, lien sameAs.
    data/sources.jsonJSONBibliographie : identifiant, titre, URL, éditeur, catégorie.
    data/search.jsonJSONIndex plein texte de toutes les pages (utilisé par la recherche du site).
    sitemap.xml · feed.xml · llms.txtXML, Atom, textePlan du site, flux des mises à jour, résumé pour les agents conversationnels.

    Exemples d'utilisation#

    Charger les résultats de Berlin 2026 dans un navigateur :

    fetch("https://ouaisfieu.github.io/extreme/data/elections.json")
  .then(r => r.json())
  .then(t => console.table(t.find(x => x.id === "de-be-2026").rows));

    Dans un tableur, importez directement l'URL d'un fichier CSV (fonction IMPORTDATA ou équivalent).
