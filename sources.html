    Sources et bibliographie

    Toutes les sources citées sur le site, classées par nature. Chaque référence renvoie vers les pages qui l'utilisent. Les sources primaires (partis, mouvements, gouvernements) sont séparées : elles documentent la manière dont les acteurs se présentent, pas une évaluation indépendante.

    Comment lire cette bibliographie. Les travaux académiques et les rapports institutionnels fondent l'analyse ; la presse sert surtout à dater et documenter les faits récents ; les encyclopédies sont des points d'entrée, pas des autorités. Les liens pointent vers les pages consultées ; certains documents peuvent avoir été déplacés depuis. La liste est aussi disponible en JSON.
